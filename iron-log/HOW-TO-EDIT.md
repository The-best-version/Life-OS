# 🏋️ دليل وخريطة تعديل تطبيق النادي (Iron Log)

هذا الدليل يوضّح لك بدقة أين تجد كل جزء في الكود إذا أردت تعديله، مع الحفاظ الكامل على سلامة الكود والبيانات.

**التطبيق صار نظاماً رياضياً متعدد التخصصات** — حديد، ملاكمة، فروسية، جري — وليس متتبّع أوزان فقط. حصص الحديد لها شاشتها الخاصة (`workout/`) بكل عمق إعداد المكينة والتقدم المزدوج، وبقية الرياضات تُسجَّل من شاشة واحدة (`session/`) تتكيّف مع الرياضة المختارة.

---

## ⚠️ قبل ما تعدّل: لا تشتغل على نفس الملف من نافذتين

إذا فتحت أكثر من جلسة Claude Code (أو نافذة VS Code ثانية) على نفس المشروع بنفس الوقت، وكلاهما يعدّل نفس الملف، كل واحدة تمسح تعديل الثانية بصمت — هذا بالضبط شكل «ما أقدر أعدّل شي». سكّر أي جلسة زايدة قبل ما تفتح ملف للتعديل اليدوي، أو تأكد إنها ما تلمس نفس الملف.

## 🧭 خريطة الملفات السريعة (أين أعدل؟)

### 1. صفحات التطبيق الرئيسية (`src/app/`)
| الصفحة | المسار | ما تحتويه |
|---|---|---|
| **الرئيسية (لوحة التقدم)** | `src/app/page.tsx` | نظرة عامة، رادار الحمل الأسبوعي بكل الرياضات، رفّ الأرقام القياسية، بطاقات الحديد (برنامج اليوم، الاستشفاء العضلي، إنذار الثبات) |
| **تسجيل حصة الحديد** | `src/app/workout/page.tsx` | شاشة تسجيل الأوزان والعدات: جدول مجموعات كثيف، مؤقّت الراحة، حاسبة البار |
| **محرّك الحصص الأخرى** | `src/app/session/page.tsx` | ملاكمة / فروسية / جري — يتكيّف حسب محرّك الرياضة (`sets` / `rounds` / `stopwatch` / `distance`) من `sports-config.ts` |
| **سجل الحصص السابقة** | `src/app/history/page.tsx` | استعراض كل التمارين والحصص السابقة بتفاصيلها |
| **التغذية والجسم** | `src/app/nutrition/page.tsx` | حاسبة السعرات، نطاق البروتين، قياسات الجسم، النوم والخطوات |
| **الإعدادات والنسخ** | `src/app/settings/page.tsx` | إدارة التمارين، الخطوات الافتراضية، تصدير واستيراد JSON |
| **الهيكل العام والشريط السفلي** | `src/app/layout.tsx` | مزوّدات الحالة، التنقل السفلي، دعم الـ RTL والخطوط |
| **الألوان والتنسيقات العامة** | `src/app/globals.css` | ثيم «ARENA» الداكن، متغيرات الألوان (volt / steel / danger / amber)، الحركة |

### 2. عناصر الواجهة والكروت (`src/components/`)
* **عناصر شاشة الحديد (`src/components/workout/`):**
  - `exercise-logger.tsx`: جدول المجموعات (مسجّلة + مسودة)، ضبط المكينة، الهدف المقترح.
  - `rest-timer.tsx`: مؤقت الراحة التنازلي العائم مع الصوت والاهتزاز — موعد نهائي لا عدّاد.
  - `add-exercise-form.tsx`: نافذة إضافة تمرين جديد إلى الحصة.
  - `plate-calculator.tsx`: حاسبة أقراص البار.
* **محرّك الرياضات الأخرى (`src/components/session/`):**
  - `sport-selector.tsx`: المبدّل العام بين الرياضات (`SportFilterProvider`/`useSportFilter`).
  - `sport-icon.tsx`: أيقونة كل رياضة ولونها (`--sport-*`).
  - `adaptive-timer.tsx`: المؤقّت المتكيّف — راحة / جولة / ساعة مفتوحة.
  - `round-tracker.tsx`: عدّاد الجولات (ملاكمة).
  - `live-session-hud.tsx`: شاشة الحصة الجارية.
  - `session-start-card.tsx`: كرت بدء الحصة.
* **رؤى عابرة للرياضات (`src/components/insights/`):**
  - `weekly-load-radar.tsx`: حلقات الحمل الأسبوعي، كل رياضة بمقياسها.
  - `trophy-shelf.tsx`: رفّ الأرقام القياسية بكل رياضة.
* **القياسات الجسدية (`src/components/body/`):**
  - `body-panel.tsx` و `health-panel.tsx`: الوزن، المحيط، النوم، الخطوات.
* **الرسوم البيانية (`src/components/charts/`):**
  - `line-area-chart.tsx` و `column-chart.tsx` و `sparkline.tsx` و `bar-list.tsx`: رسوم SVG يدوية، بدون مكتبة رسوم.
* **الهيكل والتنقل (`src/components/layout/`):**
  - `app-shell.tsx`: الترويسة العلوية، مبدّل الرياضة العام، شريط التنقل.
  - `bottom-nav.tsx`: التبويب السفلي — تبويب «التمرين» يتبع الرياضة النشطة.
* **عناصر shadcn/ui الأساسية (`src/components/ui/`):** زر، بطاقة، حقل، شيت، توست… مستخدَمة فعلياً في أكثر من مكان.

### 3. المنطق الرياضي والبيانات (`src/lib/`)
| الملف | الغرض منه |
|---|---|
| `types.ts` | تعريف الأنواع: الحديد (`Exercise`/`SetEntry`/`Session`) والرياضات الأخرى (`AthleticSession`/`SportConfig`) ومعايير العضلات MEV/MAV/MRV |
| `sports-config.ts` | **عقد الرياضات** — `SPORTS_CONFIG`: لكل رياضة محرّكها وحقولها ومقاييسها وأرقامها القياسية. إضافة رياضة جديدة تبدأ من هنا |
| `athletic-metrics.ts` | القراءات العابرة للرياضات: الحمل الأسبوعي، السلسلة بأي رياضة، الأرقام القياسية |
| `seed.ts` | البرنامج الافتراضي وكتالوج التمارين، و`DB_VERSION` |
| `metrics.ts` | كل حسابات الحديد: تقدير 1RM (معادلة Epley)، إجمالي الحجم، الاستشفاء، سلاسل الحضور |
| `repository.ts` | كل عمليات تعديل الحديد (دوال نقية + تحقق)، وكذلك فتح/تحديث/إنهاء حصص الرياضات الأخرى |
| `storage.ts` | طبقة التخزين في `localStorage` + التحقق والإصلاح والترقية (`migrate`) |
| `store.tsx` | حالة العميل (Context) والحفظ التلقائي |
| `insights.ts` | حاسبة أقراص البار ونصائح أخرى |
| `legacy-import.ts` | استيراد نسخة التطبيق القديم |
| `utils.ts` | تواريخ محلية، أرقام، تنسيق |

## ⚡ أوامر التشغيل والفحص السريع (في VS Code)

```bash
# 1. تشغيل بيئة التطوير المحلية
npm run dev

# 2. فحص الأنواع البرمجية والأخطاء بدون بناء
npm run typecheck

# 3. بناء النسخة الإنتاجية (Next.js، للتشغيل عبر سيرفر محلي)
npm run build

# 4. بناء نسخة ملف واحد قابلة للفتح مباشرة في المتصفح (بدون سيرفر)
npm run build:standalone
# الناتج: standalone/index.html — هذا هو الملف اللي يفتحه اختصار
# "افتح Iron Log.lnk" على سطح المكتب. أي تعديل على src/ لازم إعادة بناء
# الاثنين (dev build + standalone) عشان ينعكس في الاختصار.

# 5. تجربة ترقية بيانات حقيقية عبر كل خطوات migrate() دفعة وحدة
node scripts/test-migration.mjs
```

## 💡 نصائح هامة للتعديل بدون مشاكل:
1. **لا تغيّر بنية مسار التخزين:** التخزين يعتمد على مفاتيح داخلية مدروسة، أي تعديل على بنية البيانات يتم دائماً من خلال `src/lib/repository.ts` و `types.ts`، وأي حقل جديد يحتاج خطوة ترقية في `storage.ts` (`migrate()`) حتى لا تنكسر نسخة قديمة محفوظة عند المستخدم.
2. **إضافة رياضة جديدة؟** ابدأ من `src/lib/sports-config.ts` فقط — الأيقونة في `sport-icon.tsx`، ولا شيء غيرهما. كل شاشة أخرى (المحرّك، الرادار، رفّ الأرقام) تقرأ من هناك ولا تحتاج تعديلاً.
3. **التحقق من الأخطاء فوراً:** بعد أي تعديل، شغل `npm run typecheck` ليتأكد لك TypeScript أن كل الروابط والأنواع سليمة بنسبة 100%.
4. **بعد كل تعديل على `src/`:** إذا كنت تبي الاختصار على سطح المكتب (`افتح Iron Log.lnk`) يعكس التعديل، شغّل `npm run build:standalone` — هو ملف منفصل تماماً عن `next dev`/`next build` ولا يتحدّث تلقائياً.
