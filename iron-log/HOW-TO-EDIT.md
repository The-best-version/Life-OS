# 🏋️ دليل وخريطة تعديل تطبيق النادي (Iron Log)

هذا الدليل يوضّح لك بدقة أين تجد كل جزء في الكود إذا أردت تعديله، مع الحفاظ الكامل على سلامة الكود والبيانات.

---

## 🧭 خريطة الملفات السريعة (أين أعدل؟)

### 1. صفحات التطبيق الرئيسية (`src/app/`)
| الصفحة | المسار | ما تحتويه |
|---|---|---|
| **الرئيسية (لوحة التقدم)** | `src/app/page.tsx` | نظرة عامة، الرسوم البيانية، السلسلة، الأرقام القياسية |
| **تسجيل التمرين اليومي** | `src/app/workout/page.tsx` | شاشة تسجيل الأوزان والعدات والمؤقت أثناء التمرين |
| **سجل الحصص السابقة** | `src/app/history/page.tsx` | استعراض كل التمارين والحصص السابقة بتفاصيلها |
| **التغذية والبروتين** | `src/app/nutrition/page.tsx` | حاسبة السعرات ونطاق البروتين اليومي |
| **الإعدادات والنسخ** | `src/app/settings/page.tsx` | إدارة التمارين، الخطوات الافتراضية، تصدير واستيراد JSON |
| **الهيكل العام والشريط السفلي** | `src/app/layout.tsx` | مزودات الحالة، التنقل السفلي، دعم الـ RTL والخطوط |
| **الألوان والتنسيقات العامة** | `src/app/globals.css` | ثيم الحديد الداكن، المتغيرات اللونية، أزرار ومؤثرات الحركة |

---

### 2. عناصر الواجهة والكروت (`src/components/`)
* **عناصر شاشة التمرين (`src/components/workout/`):**
  - `exercise-logger.tsx`: تسجيل المجموعات، ضبط المكينة، RPE، زر الحفظ والهدف المقترح.
  - `rest-timer.tsx`: مؤقت الراحة التنازلي العائم مع الصوت والاهتزاز.
  - `add-exercise-form.tsx`: نافذة إضافة تمرين جديد إلى الحصة.
* **كروت لوحة التقدم (`src/components/dashboard/`):**
  - `studio-hero.tsx`: ترويسة الشاشة الرئيسية وإحصائيات الحصة القادمة.
  - `volume-landmarks-card.tsx`: كرت الجرعة الأسبوعية لكل عضلة (MEV / MAV / MRV).
  - `stall-card.tsx`: رادار التمارين الواقفة التي ثبت وزنها.
  - `records-card.tsx`: كرت الأرقام القياسية المحققة (PRs).
  - `consistency-card.tsx`: سلسلة الاستمرارية والتواجد في النادي.
* **القياسات الجسدية (`src/components/body/`):**
  - `body-panel.tsx`: تتبع الوزن وقياسات المحيط (خصر، صدر، باي، فخذ).
* **الرسوم البيانية (`src/components/charts/`):**
  - `line-area-chart.tsx` & `column-chart.tsx`: رسوم SVG خفيفة ودقيقة للتقدم.

---

### 3. المنطق الرياضي والبيانات (`src/lib/`)
| الملف | الغرض منه |
|---|---|
| `types.ts` | تعريف الأنواع (المجموعات، التمارين، معايير العضلات MEV/MAV/MRV) |
| `seed.ts` | قائمة التمارين الافتراضية المدمجة مع التطبيق عند أول تشغيل |
| `metrics.ts` | كل معادلات الحسابات: تقدير 1RM (معادلة Epley)، إجمالي الحجم، فحص الثبات |
| `repository.ts` | دوال إضافة وحذف وتعديل المجموعات والتمارين والتحقق من صحتها |
| `storage.ts` | طبقة الحفظ في `localStorage` والنسخ الاحتياطي واستعادة البيانات التالفة |
| `store.tsx` | إدارة الحالة العامة المشتركة بين جميع الشاشات |

## ⚡ أوامر التشغيل والفحص السريع (في VS Code)

يمكنك تشغيل هذه الأوامر مباشرة من الطرفية (Terminal) أو من خلال قائمة **Terminal -> Run Task**:

```bash
# 1. تشغيل بيئة التطوير المحلية
npm run dev

# 2. فحص الأنواع البرمجية والأخطاء بدون بناء
npm run typecheck

# 3. بناء النسخة الإنتاجية
npm run build
```

---

## 💡 نصائح هامة للتعديل بدون مشاكل:
1. **لا تغيّر بنية مسار التخزين:** التخزين يعتمد على مفاتيح داخلية مدروسة، أي تعديل على بنية البيانات يتم دائماً من خلال `src/lib/repository.ts` و `types.ts`.
2. **التحقق من الأخطاء فوراً:** بعد أي تعديل، شغل `npm run typecheck` ليتأكد لك TypeScript أن كل الروابط والأنواع سليمة بنسبة 100%.
