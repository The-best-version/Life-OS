# بوت تيليجرام — 2027 Life OS

النظام كلّه في جيبك: تسجيل بجملة، وأجوبة عن أسئلتك، ومدرّب يقرأ يومك ويقرّر
بنفسه هل عنده ما يستحقّ أن يُقاطعك. البوت **لا يملك بيانات**: كل تغيير يمرّ على
`POST /sync` في `services/local-sync-server.js`، وكل صفّ يكتبه تبنيه نفس دالة
الشكل التي تستخدمها الشاشات (`expenseShape` و`incomeShape` و`taskShape`
و`urgeShape` و`sessionShape`).

---

## التشغيل في ثلاث خطوات

**١) ثبّت الحزمة** (مرة واحدة — `grammy` وحدها، ولا شيء غيرها):

```bash
npm run bot:install
```

**٢) املأ الإعدادات**:

```bash
copy "services\telegram-bot\.env.example" "services\telegram-bot\.env"
```

ثم افتح `.env` واملأ:

| المفتاح | من أين |
|---|---|
| `TELEGRAM_BOT_TOKEN` | `@BotFather` في تيليجرام → `/newbot` → ينسخ لك التوكن. **هذا هو السر الوحيد.** |
| `TELEGRAM_CHAT_ID` | أرسل أي رسالة للبوت، ثم `npm run bot:whoami` — يطبع رقمك. |

`.env` مُستثنى في `.gitignore` ولا يُرفَع. `.env.example` هو النسخة المرفوعة
وفيها قيم وهمية فقط.

**٣) شغّله**:

```bash
npm run bot
```

ليبدأ مع ويندوز: ضع مختصرًا لـ `services/launchers/run-telegram-bot.vbs` في
`shell:startup`. **نسخة واحدة فقط** — عميلان على نفس التوكن يسرق كلٌّ منهما
تحديثات الآخر، والعرض الظاهر بوت يردّ على كل رسالة ثانية.

## كيف تخاطبه

لا أوامر تُحفظ. أرسل جملة:

| ترسل | يصير |
|---|---|
| `صرفت ٣٥ غداء` | مصروف في شاشة المالية، والرصيد يتحدّث |
| `دخل ١٥٠٠ استشارة` | دخل |
| `دخل ٣٠٠ توصيل ٤ ساعات` | دخل مع ساعاته، فيدخل في معدّل الساعة |
| `كاس ماء` / `ماء ٣` | عدّاد الماء |
| `تمت صلاة العصر` | تسجيل العادة التي تُشبه الكلمات |
| `اليوم: راجع المحاسبة` | من مهام اليوم الثلاث |
| `قرأت ٢٠ صفحة` | جلسة قراءة، ويتقدّم عدّاد الكتاب المعلَّم «أقرأه الآن» |
| `قرأت ١٠ صفحات من سيكولوجية المال` | **الكتاب بالاسم** — وإملاء مكسور يُطابَق، والمتشابهان يُسألان ولا يُخمَّنان. وغير الموجود يُضاف بضغطة ويُسجَّل عليه |
| `فائدة المال حرية لا رفاهية` | **فائدة تُحفظ على الكتاب بصفحتها** — وتعود إليك غدًا، ثم بعد ٣ و٧ و٢١ و٦٠ يومًا |
| `درس الكتاب لا تُقلّد أحدًا` | الجملة الواحدة التي يُلخّصها الكتاب (`book.lesson`) |
| `أضف كتاب الأب الغني تأليف كيوساكي` | على الرف — والعنوان الموجود يُعاد لا يُكرَّر |
| `ابدأ كتاب العمل العميق` | «أقرأه الآن»، ويصير هو الكتاب الذي تنزل عليه الصفحات والفوائد |
| `خلصت كتاب سيكولوجية المال` | يُنهيه ويختمه بتاريخه، يقول كم صفحة على كم يوم، ويعرض النجوم ويسأل عن الدرس |
| `راجع` · `/review` | **نقطة واحدة مستحقّة** — إشارة أولًا، ثم كشف، ثم «تذكّرتها / ما تذكّرتها» |
| `مكتبتي` · `/books` | الرف: أين وصل كل كتاب، كم بقي، وكم فائدة تنتظر |
| `ابدأ تركيز` / `ابدأ تركيز ٥٠ مراجعة` | جولة بومودورو **تعدّ فعلًا**، والجرس يصلك هنا |
| `وقفة` · `أكمل` · `أوقف` · `استراحة` | إدارة الجولة القائمة من الجوّال |
| `ركزت ٤٥ دقيقة على المحاسبة` | جولة عُمِلت بعيدًا عن أي شاشة |
| `صمدت` / `سقطت` | أمام عادة في كاسر العادات — ثم يسأل عن المحرّك، والسؤال يُتجاوَز |
| `شتتني الجوال` ثم `الحل أتركه في الدرج` | تقييم المساء، يُكتب على صفّ اليوم |
| `موعد بكرة ٥ م الدكتور` | في التقويم، وينبّهك قبله بالدقائق التي تختارها |
| `غياب محاسبة` | غياب واحد — ويرفض الثاني في نفس اليوم |
| `درجة محاسبة الكويز ١٨ من ٢٠` | في كشف المادة |
| `هدف الحفظ ٣٠` / `هدف الحفظ +٥` | يضبط عدّاد الهدف أو يزيده |
| `أمس صرفت ٣٥ غداء` · `قبل يومين دخل ٢٠٠` | يُسجَّل في ذلك اليوم، ويقول لك أين نزل |
| `أمس تمت صلاة العصر` | يصحّح صفّ ذلك اليوم وحده — واليوم لا يتحرّك |
| `ألغِ قراءة` | يزيل التأشير، ويسحب صفحات اليوم ويرجّع عدّاد الكتاب |
| `ابحث عن التسويف` | في المهام والكتب والتقييمات والأهداف والمصاريف |
| 🎙️ مقطع صوتي | يُفرَّغ ويُقرأ كأنك كتبته |
| أي نصّ آخر | صندوق الوارد — مربّع «مهم غير عاجل» في المصفوفة |

الأرقام العربية (`٣٥`) والفاصلة العربية (`١٢٫٥`) مفهومة، وكلمة «ريال» تُنزع من
الوصف ولا تُخزَّن.

### والسؤال يُجاب، ولا يُسجَّل

الجملة التي تبدأ بكلمة استفهام أو تنتهي بعلامة استفهام **ليست مهمة**. كانت
«كم صرفت هذا الشهر؟» تنزل في صندوق الوارد كأنها شيء ينبغي فعله — جواب خاطئ،
وصفّ عليه أن يحذفه بعدها.

| تسأل | يجيب |
|---|---|
| `كم صرفت هذا الشهر؟` | المجموع، وأكبر ثلاثة بنود تحته، والمعدّل اليومي |
| `كم دخلي هذا الأسبوع؟` | الدخل، ومعدّل الساعة إن كانت الساعات مسجّلة |
| `وين وصلت في الكتاب؟` | صفحات اليوم، السلسلة، أين وصل الكتاب، **وكم يومًا يبقى عليه بهذا المعدّل** |
| `كم فائدة كتبت؟` | آخر الفوائد بكتبها وصفحاتها، وكم منها ينتظر المراجعة |
| `متى الصلاة القادمة؟` | القادمة وكم بقي عليها، ثم أوقات اليوم كلها |
| `كم انتظامي؟` | النسبة، المحتسَب من العادات، والسلسلة |
| `ايش مهامي؟` · `ايش باقي؟` | الثلاث، أو العادات المفتوحة وتحتها أزرارها |
| `كم تركيزي اليوم؟` | الدقائق، الجولات، السلسلة، وأخصب ساعاتك |
| `محاضراتي؟` · `اختباراتي؟` | محاضرات اليوم، والمستحقّ من مكتب الجامعة |
| `أهدافي؟` | أهداف الربع المفتوحة ونسبة كلّ منها |

«هذا الشهر» و«هذا الأسبوع» و«آخر ١٠ أيام» تُقرأ كنافذة زمنية مستقلّة عن
الموضوع.

تحت كل كتابة زرّ **↩︎ تراجع**. وأوامر قليلة لما لا تقوله جملة: `/today`،
`/now`، `/coach`، `/week`، `/focus`، `/books`، `/review`، `/menu`، `/morning`،
`/evening` — أو بالعربي كنصّ: «يومي»، «باقي»، «المدرّب»، «الأسبوع»، «مكتبتي»،
«راجع»، «القائمة»، «صباح»، «مساء».
(تيليجرام لا يعدّ `/صباح` أمرًا، فالكلمات العربية تُقرأ كنصّ.)

## ما يرسله دون طلب

كله مضبوط من شاشة **«بوت تيليجرام»** داخل الموقع، لا من هذا المجلد: الشاشة
تكتب `state.bot` كأي شاشة أخرى، والقرص يحمله، والبوت يقرؤه كل دقيقة ويعيد
تسليح مؤقّتاته إن تغيّر. **لا قناة أوامر بين الشاشة والعملية** — ولهذا جدول
عدّلته والبوت مطفأ هو نفسه الجدول حين يعود.

| | |
|---|---|
| موجز الصباح | الصلوات، أهم ثلاث مهام، عبارة اليوم |
| إقفال المساء | جرد ما أُنجز، وأزرار لما بقي |
| الماء | كل ساعتين داخل نافذة تختارها — ونصّه يعرف كم كوبًا بقي |
| قبل الأذان | قبل كل صلاة بالدقائق التي تحدّدها. الشروق ليس صلاة |
| جرد المهام | مرة يوميًا، **وصامت إن لم يبقَ شيء** |
| **المدرّب** | يقرأ اليوم كلّه ويقرّر بنفسه هل عنده ما يُقال — وغالبًا لا |
| **مراجعة الأسبوع** | يوم واحد في الأسبوع: المتوسط، الأيام بدون تسجيل، أثبت عادة وأضعفها |
| **مراجعة الفوائد** | نقطة واحدة من كتاب قرأته، بصفحتها — **وصامت في الليلة التي لا شيء فيها مستحقّ** |
| **عادات البلوك** | عند فتح كل بلوك فعلًا — بالصلوات لا بالساعة — وصامت إن لم يبقَ منه شيء |
| **قبل المواعيد** | المواعيد المؤقّتة في مربّع اليوم، قبلها بالدقائق التي تختارها |
| تذكيرات بنصّك | جملة وساعة وأيام — حتى ١٢ تذكيرًا |
| **جرس الجولة** | ليس في الجدول: يُسلَّح من `run.endAt` حين تبدأ جولة، ويكتب الجلسة بنفسه إن كان الحاسب مغلقًا |

نصّ كل واحد يُبنى من حالة اليوم **لحظة الإرسال** لا لحظة التسليح: تذكير ماء
سُلّح السابعة صباحًا ويقول «باقي ٨ أكواب» الثالثة عصرًا هو تذكير توقّف عن أن
يكون صحيحًا.

### المدرّب، وصمته

المدرّب هو المُدخَل الوحيد في الجدول الذي **يقرّر بنفسه هل يتكلّم**. يفحص:
الرجوع بعد غياب، ساعة السقوط التي يعرفها سجلّ الكاسر، المستحقّ الجامعي،
السلسلة الليلة، عادة بعينها لها سلسلة طويلة ولم تُسجَّل، جولة تركيز معلّقة،
الثلاث غير المختارة، تجهيز الغد، التقييم، القراءة، التركيز، الماء، وقفزة
الصرف. يرتّبها، يرسل **أهم ثلاث مع أزرارها**، ويقول كم ترك.

وفي اليوم الذي لا شيء فيه يستحقّ القول **لا يرسل شيئًا**. هذا ليس نقصًا، هذا
هو السبب في أنه يستحقّ أن يبقى مشتغلًا: الإشعار الذي يرنّ ليقول «كل شي تمام»
هو الذي يعلّمك أن تمسح الذي بعده دون قراءة. «المدرّب» كلمةً في المحادثة
تستدعيه في أي وقت — وهناك فقط له أرضية: الزرّ الذي يُضغَط ويردّ بالصمت يُقرأ
بوتًا ميّتًا.

**وتحت كل رسالة غير مطلوبة زرّ «لاحقًا».** التذكير الذي لا يمكن تأجيله
هو الذي تُطفئه، والتذكير المُطفأ يأخذ معه بقيّة الجدول. والمؤجَّل يُعاد بناء
نصّه لحظة عودته لا لحظة تأجيله — تذكير ماء أجّلته الحادية عشرة يقول ما بقي
عند الثانية عشرة.

**وكل ملاحظة تحمل زرّ الحلّ.** «انتباه، انتظامك ٤٠٪» درجة؛ «باقي عادتان —
اضغط إحداها» حركة. والحدّ الأدنى للعادة (`habit.min`) يظهر زرًّا بجانب العادة
نفسها، لأن قيمته كلّها في أن يكون مرئيًّا في اللحظة التي يبدو فيها التخطّي
معقولًا.

### المكتبة: الصفحة نصف الطريق

تسجيل الصفحات هو النصف الرخيص. النصف الذي كان مفقودًا من الجوّال هو **الجملة
التي تستطيع قولها عن تلك الصفحات بعد أسبوع** — ولهذا بعد كل تسجيل قراءة يسأل
البوت سؤالًا واحدًا: «وما أكبر فائدة من قراءة اليوم؟». يسأل ولا ينتظر: لا شيء
معلّق، ولا جواب مطلوب، وتجاهله يكلّفك النقطة ولا شيء غيرها. ولا يسأل مرّتين في
مساء واحد.

والفائدة التي تُكتب **تُجدوَل**: تعود غدًا، ثم بعد ٣ أيام، ثم ٧، ثم ٢١، ثم ٦٠.
تعود **بإشارتها أولًا** — أول أربع كلمات منها — ثم تكشفها بضغطة، ثم تقول
«تذكّرتها» فتتباعد، أو «ما تذكّرتها» فترجع غدًا من أول السلّم. إعادة القراءة
ليست استدعاءً، والاستدعاء هو وحده الذي يُبقي.

ونقطة كُتبت على الحاسب تدخل الدورة نفسها: `noteShape` هو المكان الوحيد الذي
تُكتب فيه حقول النقطة، ومكتب الكتاب في الموقع يكتب من خلاله. والنقاط التي
كُتبت قبل وجود الجدولة أصلًا تُقرأ **مستحقّة الآن** — لأن النقطة التي لم
يراجعها أحد هي بالضبط نقطة تنتظر، فلا فرع في `migrate` خمّن شيئًا.

وتحت النقطة التي تذكّرتها زرّ واحد: **«اجعلها مهمة»**. لأن الفائدة التي لا
تتحوّل إلى فعل هي اقتباس جميل.

## الملفات

| الملف | ماذا فيه |
|---|---|
| `bot.js` | المدخل: البوّابة الأمنية، التوجيه، الأزرار، جرس التراجع، جدولة الموجزين |
| `lifeos-client.js` | **الوصلة الوحيدة بالحالة**: `GET /state`، `POST /sync` بـ rev+1، طابور كاتب واحد |
| `parse.js` | قراءة الجملة العربية — جدول كلمات بادئة، لا قواعد نحوية |
| `actions.js` | التغييرات نفسها، كلها دوال نقية: `(state, args) → { next, before }` |
| `views.js` | النصوص العربية ولوحات الأزرار |
| `voice.js` | تنزيل المقطع وتفريغه — الشيء الوحيد هنا الذي يخرج من هذا الجهاز، وينتهي حيث يبدأ `parse` |
| `insight.js` | **المدرّب**: يقرأ اليوم كلّه، يرتّب ما يستحقّ القول، ويعيد قائمة فارغة في اليوم الذي لا شيء فيه |
| `ask.js` | أجوبة الأسئلة، والبحث، ومراجعة الأسبوع — قراءات للحالة تتحوّل عربيّة |
| `fmt.js` | الأرقام العربية، والعلامة من اليمين لليسار، ومخطّط الأسبوع بحروف الكتل. خرجت من `views.js` يوم احتاجها ملفّان، لأن `views.js` يستورد grammY |
| `reminders.js` | ما يرسله البوت دون طلب: `planToday`، نصّ كل تذكير، `Scheduler`، `Bell`، وعبارة اليوم |
| `health.js` | المنفذ ٤٧٦١٦ — `GET /health` لشريط الحالة في الموقع، و`POST /ping` للرسالة التجريبية |
| `whoami.js` | يطبع رقم المحادثة. سكريبت منفصل وليس أمرًا في البوت — أمر يردّ قبل القائمة البيضاء هو أمر يردّ على الغرباء |
| `config.js` | قراءة `.env` باليد، والرفض المبكّر إذا نقص شيء |

`parse.js` و`actions.js` و`reminders.js` و`insight.js` و`ask.js` و`fmt.js` لا
يستورد أيٌّ منها `grammy` ولا يتّصل بشبكة، ولهذا تحملها الثلاثة:
`tests/bot.test.mjs` و`tests/bot-coach.test.mjs` و`tests/bot-reach.test.mjs`،
ويشغّلها البناء قبل كل بناء. **هذا قيد وليس ملاحظة**: استيراد grammY في أيٍّ
منها يُخرجه من الاختبار في نفس اللحظة.

وقد أمسك `tests/bot-reach.test.mjs` خطأين حقيقيين أول مرة شُغّل: `rows()` تُرجع
صفوف الكائنات وتُسقط النصوص، و`absentOn` قائمة تواريخ — فحارس «غياب مرّتين في
يوم» لم يعمل ولا مرّة؛ و`markShape` ترفع «من ٠» إلى ١٠٠، فكانت «١٨ من ٠» ستُخزَّن
ثمانية عشر من مئة.

## ثلاث حقائق معمارية

**١) البوت كاتب ثالث، ويمرّ من نفس الباب.** النافذة في المتصفّح هي الكاتب
الأول، والاسترجاع من مركز النسخ هو الثاني. كل ضمانات الكتابة موجودة أصلًا في
الخادم: رقم المراجعة، رفض الكتابة المتأخّرة، حفظ النسخة السابقة في `.prev.json`،
وحراسة الكتابة التي تُنقِص صفوفًا في `backups/guard/`. الكتابة المباشرة على
`graphify-out/data/lifeos.json` تتجاوزها جميعًا، ولهذا لا يعرف أيّ ملفٍ هنا
ذلك المسار.

البوت لا يرسل ترويسة `Origin`. الخادم يسمح بـ `POST /sync` من الأصل الذي يخدمه
وحده، وله فتحة واحدة: طلب بلا `Origin` إطلاقًا هو «curl وأدوات هذا الجهاز» —
وهذا هو. لا تُضف ترويسة `Origin` هنا.

**٢) إذا كانت النافذة مفتوحة أثناء كتابة البوت، يظهر شريط التعارض.** النافذة
تحمل الآن مراجعة أقدم من القرص، فتُرفَض كتابتها التالية ويظهر الشريط —
و«حمّل الأحدث» يعتمد نسخة القرص وفيها صفّ البوت. هذا هو الجواب المقصود ولا شيء
يُفقَد في الحالتين. عمليًا البوت يُستخدم والحاسب مغلق.

**٣) أول رسالة في يوم جديد تُدوّر اليوم.** إن كانت النسخة على القرص لا تزال
تحمل يوم أمس (لأن أحدًا لم يفتح التطبيق)، يمرّ البوت على `rollDay` من طبقة
الحالة قبل الكتابة — نفس مسار `loadState` في التطبيق، بالضبط: `migrate` ثم
`rollDay`. وبغير ذلك كانت تِكّة اليوم تُكتب على كشف أمس.
